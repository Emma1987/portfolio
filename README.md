## 📁 Portfolio

### 🎯 Purpose
This is my personal developer portfolio, built with Symfony, Twig, and Symfony UX. It showcases selected professional projects I've worked on, along with a few personal ones I care about.

### ✨ Highlights
• Multilingual interface (French 🇫🇷 / English 🇬🇧)  
• Project showcase with detailed case studies and tech stacks 🛠️  
• Interactive “Recruiter Game” to answer classic interview questions 🎮  
• About section to get to know me better (spoiler: I love coffee and storms) ☕🌩️  
• Contact section for easy reach-out 📬  
• Admin panel to manage all portfolio content  
• UX focus with fun touches and fully responsive design 📱💻  

### 🛠️ Tech Stack
• Symfony 7.3  
• Twig & AssetMapper  
• Symfony UX (Turbo, Stimulus, Twig Components)  
• MySQL / Doctrine  
• GitHub Actions CI
